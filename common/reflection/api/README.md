# surf-api-reflection-api

Reflection proxies over classes that cannot be compiled against, used by the NMS bridges.

- `@ReflectionProxy` interfaces and their member annotations
- `ReflectionProxies` and `reflectionProxy<T>()`, which back each interface with a hidden class
  generated by the invoker generator of `surf-api-common-api`

The implementation lives here because `reflectionProxy<T>()` is a public inline function that
plugin bytecode calls directly. `ReflectionProxyContributor` in `surf-api-core-impl` registers the
proxies in every plugin context.
