# surf-api-nats-core

The JVM implementation and the Node.js client `@slne/surf-api-nats`, including the protoc plugin `protoc-gen-surf-nats`.
A Kotlin Multiplatform module; its JS end-to-end tests start NATS servers in Docker.

See [surf-nats](../README.md#modules) for the library and all of its modules.
