# CommandAPI provenance

This Kotlin command API port retains concepts
from [CommandAPI](https://github.com/CommandAPI/CommandAPI), version 12.0.0, revision
`740a093a7d111863067eb3f94a3041e69ade02fa`.

The retained API concepts include parsed command arguments and command syntax and validation
failures. The Minestom backend is original Kotlin and does not include Bukkit, Paper, NMS,
Brigadier, or CommandAPI runtime code.
