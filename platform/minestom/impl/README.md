# surf-api-minestom-impl

The surf-api runtime for a Minestom server.

- `surfMinestomServer { }` and the server lifecycle
- the Mixin agent and the mixins into Minestom
- the implementations of the Minestom API

The aggregate `surf-api-minestom-server` exposes this module to server projects. See the
`surf-api-minestom` skill.
