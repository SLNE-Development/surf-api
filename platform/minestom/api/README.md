# surf-api-minestom-api

The Minestom-specific API.

- commands, dialogs, inventory views, events and coroutine dispatchers
- async and signed chat contracts, NPCs, player visibility and block highlights
- `SurfMinestomPlugin` and `SurfMinestomPlayer`

Downstream plugins depend on the aggregate `surf-api-minestom`. See the `surf-api-minestom` skill.
