# surf-api-paper-api

The Paper-specific API.

- commands, dialogs, inventory views, sidebars, glowing and the visualizer
- packet listeners and packet lore, block PDC, permissions and the PlaceholderAPI hook
- `PaperDispatchers`, the plugin base classes and the NMS bridge interfaces

Downstream projects depend on the aggregate `surf-api-paper`. See the `surf-api-paper` skill.
